# Changelog

## v0.2.0 — 2026-09-21

Promotes lessons from a successful four-project manager takeover and closure run.

Adds:
- isolated snapshot / manager-branch takeover guidance;
- stronger separation between certified runtime heads and later documentation-only closure heads;
- freshness checks for stale or cached observability;
- safe superseding of abandoned pull requests only after the replacement path is verified;
- explicit post-closure scope discipline: closing the current unit does not authorize the next unit;
- case 007 documenting a complete multi-project takeover from stale workers to verified closure;
- four new manager decision evals covering takeover isolation, stale observability, runtime-vs-doc certification, and next-round boundaries.

## v0.1.0 — 2026-09-21

Initial AEM playbook.

Introduces:
- autonomous engineering-manager charter;
- evidence-first and action-first operating loop;
- ordinary engineering decision authority;
- owner escalation policy;
- stale-active detection and writer takeover;
- one-writer safety model;
- project-state and handoff templates;
- Work bootstrap prompt;
- first casebook derived from a four-project unattended management run;
- decision eval suite.
