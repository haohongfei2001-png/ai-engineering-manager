## Executive summary

State what actually advanced, what closed, what remains blocked, and whether owner action is required.

## Project table

| Project | Verified start state | Key actions | Verified end state | Next action |
|---|---|---|---|---|

## Durable evidence

For each project list:
- remote heads / PRs;
- required checks;
- real-product or browser evidence;
- canonical status;
- reports / receipts.

## Takeovers

Record any stale-worker takeover:
- old executor;
- why it was considered stale;
- writer lease release evidence;
- new executor;
- first verified progress after takeover.

## Blockers

Distinguish:
- technical;
- environment;
- authority;
- product-owner.

## Lessons

Separate:
- one-off incident;
- candidate reusable policy;
- candidate casebook entry;
- candidate eval.

Do not promote a lesson to a universal rule without a general reason.
